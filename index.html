Bitácora de Aprendizaje

GitHub + HTML + CSS | Proyecto de Gael y Fanny

Objetivo

Documentar el proceso de creación de una página web usando HTML, CSS y el control de versiones con GitHub Pages.

Día 1 - Introducción a GitHub

¿Qué es GitHub?

GitHub es una plataforma para guardar código, llevar control de versiones con Git y colaborar. Permite alojar páginas web gratis con GitHub Pages. Creamos cuenta, configuramos Git y creamos nuestro primer repositorio bitacora-gf.

Día 2 - HTML

Estructura con HTML

HTML (HyperText Markup Language) es el esqueleto de la web. Usamos etiquetas como <header>, <div>, <h1> y <p> para organizar la información de la bitácora.

Día 3 - CSS

Estilos con CSS

CSS (Cascading Style Sheets) es lo que da color, forma y diseño. Aplicamos colores, bordes redondeados, sombras y un diseño responsive para que se vea bien en celular.

Día 4 - Subir la Bitácora a GitHub

Proceso para subir

1. Hacer git add .
2. Hacer git commit -m "Subo mi bitácora"
3. Hacer git push origin main
4. Activar GitHub Pages en Settings > Pages > Branch: main

La página queda publicada en: https://usuario.github.io/bitacora-gf/

Día 5 - Conclusión

Aprendizaje

Aprendimos que GitHub no solo es para guardar código, sino para publicar proyectos reales. HTML pone el contenido y CSS lo hace visualmente atractivo. La combinación permite crear desde una bitácora hasta una página profesional.
